FOR HUMANS AND AGENTS

A small handoff
that does more.

One agent-authored sequence drives a visible review and reports its assertions to a local process.

01

Author

Add a focused demo beside the feature. Use DOM actions and assertions that prove the behavior you want reviewed.

02

Watch

Start the existing dev server. Open the printed URL in any user-facing browser on the same machine. The app navigates and acts on its own.

03

Read the result

Leave the browser alone. The local CLI receives a step-by-step result and exits successfully only when the scripted checks pass.

READABLE BY DESIGN

A demo is just
small code.

The browser performs real clicks and fills. A local listener collects the outcome. No separate test browser is needed for this supported development workflow.

A passing demo verifies its own assertions. It does not replace browser automation for cross-browser suites, screenshots, network inspection, or flows outside this API.

demos/launch-review.ts
import { demo } from 'agent-demo-kit';

export default demo('launch-review', async ({ page }) => {
  await page.goto('/workspace');
  await page.getByRole('button', { name: 'Board' }).click();
  await page.getByRole('heading', { name: 'Ready' })
    .expectVisible();
});
local CLI
agent-demo listen --demo launch-review \
  --url http://localhost:5173/ --json result.json
