ONE DEMO, TWO AUDIENCES

From code to clarity.

Agent-authored actions run against the actual rendered UI. The same sequence serves human review and a checked CLI result.

01

Author a small script

The agent adds DOM actions and explicit assertions beside the React feature. No separate browser automation suite is required for this path.

02

Open the normal dev URL

Append ?demo=launch-review. Watch navigation, clicks, typing, and checks in your own browser. Change the delay on the card while it runs.

03

Collect a concrete result

A local listener receives the final status, every step, and a JSON artifact. Missing or ambiguous elements fail with a specific reason.

SMALL BY DESIGN

Readable for people.
Structured for agents.

The browser runs the demo. The package adds a React entry point, a focused action API, a quiet playback card, and an optional local CLI listener.

A pass verifies the assertions the demo actually makes. It does not claim that every part of a feature has been tested.

demos/launch-review.ts
const review = demo('launch-review', async ({ page }) => {
  await page.goto('/workspace');
  await page.getByRole('button', { name: 'Board' }).click();
  await page.getByRole('heading', { name: 'Ready' })
    .expectVisible();
});
